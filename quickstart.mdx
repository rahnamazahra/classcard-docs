Follow this guide to clone the repository, install dependencies, configure your environment, and spin up the backend application.

## Prerequisites

Before starting, ensure you have the following installed on your local machine:

* **PHP** `>= 8.2` (with standard extensions: `pdo`, `mbstring`, `openssl`, `bcmath`, `xml`)
* **Composer** `>= 2.x`
* **Node.js** `>= 18.x` & **NPM**
* **PostgreSQL** or **MySQL** (PostgreSQL recommended for multi-tenant schema support)

---

## Getting Started

<Steps>
  <Step title="Clone the Repository">
    First, clone the Classcard repository from GitHub and navigate into the project directory:

    ```bash
    git clone git@github.com:pixy-group/classcard.git
    cd classcard
    ```
  </Step>

  <Step title="Install PHP & Node Dependencies">
    Install backend PHP packages via Composer, and frontend asset dependencies via NPM:

    <CodeGroup>
    ```bash Composer (Backend)
    composer install
    ```

    ```bash NPM (Frontend)
    npm install
    ```
    </CodeGroup>
  </Step>

  <Step title="Environment Configuration">
    Copy the example environment configuration file to create your local `.env` file:

    ```bash
    cp .env.example .env
    ```

    Open the `.env` file in your editor and update your database credentials and application settings:

    ```ini .env
    APP_NAME=Classcard
    APP_ENV=local
    APP_KEY=
    APP_URL=http://localhost:8000

    DB_CONNECTION=pgsql
    DB_HOST=127.0.01
    DB_PORT=5432
    DB_DATABASE=classcard_dev
    DB_USERNAME=postgres
    DB_PASSWORD=secret
    ```
  </Step>

  <Step title="Generate Application Key">
    Generate a new unique application key for encryption and session security:

    ```bash
    php artisan key:generate
    ```
  </Step>

  <Step title="Run Database Migrations & Seeders">
    Ensure your database server is running, then execute the migrations to build the landlord/tenant database schemas:

    ```bash
    php artisan migrate --seed
    ```

    <Note>
      The `--seed` flag populates initial roles, permissions, and demo system settings.
    </Note>
  </Step>

  <Step title="Start Local Development Servers">
    Run the Laravel development server alongside Vite for asset bundling:

    <CodeGroup>
    ```bash Laravel Server
    php artisan serve
    ```

    ```bash Vite Dev Server
    npm run dev
    ```
    </CodeGroup>

    Your local application will now be accessible at `http://127.0.0.1:8000`.
  </Step>
</Steps>
